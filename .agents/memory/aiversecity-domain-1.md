description: Competition requirements for the 3AM SDC Hackathon workforce-readiness project.

The 3AM SDC Hackathon project is for Aiversecity's Future-Ready Workforce Domain (Domain 1), with a three-person team. The required capabilities are skills profile intake, AI-trend signals, explainable future-role matching, personalised reskilling pathways, SDG mapping, and multiple future scenarios for uncertainty.

**Why:** These are compulsory competition requirements supplied by the team and are not recoverable from implementation code.

**How to apply:** Use all six capabilities as acceptance criteria when future feature work is planned; keep implementation sequencing aligned with the team's explicit requests.
