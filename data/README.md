# Synthetic career dataset

Generated by node scripts/generate_synthetic_data.mjs. Goal names, summaries, selected target wording, and icon links are reference data from the United Nations Sustainable Development Goals. Role-skill links and alignment weights are curated illustrative examples, not measured SDG impact. No files contain observed job-posting, wage, employment, SDG-impact, or measured AI-adoption data.

- unified_profile_career_dataset.csv: canonical learner-row table combining the 2,880 synthetic model profiles with the registration profile schema. It contains synthetic role-matching features and labels; name, school, grades, awards, work history, and other personal narrative fields are intentionally blank because the source data does not provide them. Skills and categorized interests are serialized as JSON arrays, and experiences are an empty JSON array.
- synthetic_role_profiles.csv: original compact model-training features, retained for reference.
- synthetic_skill_scenarios.csv: simulated skill-demand indices by role, year (2024-2032), and moderate/fast AI-adoption scenario.
- synthetic_sdg_skill_mappings.csv: illustrative role-skill-to-target links and weights used to rank a role's best-supported goals from the full 17-goal catalog.
- sdg_goal_reference.csv: UN goal summaries and two subdomain references per goal, with icon image URLs from the Open SDG icon translations library.
- Scores demonstrate model mechanics only. Replace or recalibrate them with public trend signals and reviewed mapping evidence before making real-world claims.
